# 貸款計算器

純前端的貸款試算工具：輸入金額、期限、利率與還款方式，立即產生**完整還款計畫明細表**與彙總資訊。免安裝、免後端、免網路連線，直接用瀏覽器打開 `index.html` 就能用。

![tests](https://github.com/jackywang869-cmyk/loan-calculator/actions/workflows/tests.yml/badge.svg)

## 功能

- **輸入**
  - 貸款金額（可輸入千分位，如 `3,000,000`）
  - 貸款期限：**年 / 月** 兩種單位，切換時自動換算（1 年 = 12 個月）
  - 利率：**年利率 / 月利率** 兩種單位，切換時自動換算（年利率 ÷ 12）
  - 還款方式：**等額本息**（每期還款額固定）、**等額本金**（每期本金固定）
  - 繳款週期：月繳 / 季繳 / 半年繳 / 年繳
- **輸出**
  - 逐期明細表：期數、當期還款額、當期本金、當期利息、累計已還利息、剩餘本金
  - 彙總資訊：首期與末期還款金額、還款總額、本金總額、利息總額、利息佔貸款金額比例
  - 每期本金／利息結構圖與剩餘本金曲線
  - 明細表可一鍵展開全部期數、可匯出 CSV
- **品質**
  - 金額統一四捨五入至兩位小數，並顯示千分位符號
  - 所有輸入都有驗證，錯誤時在該欄位下方顯示明確的中文提示
  - 金額全程以「分」為單位做整數運算，避免浮點累計誤差
  - 計算邏輯與介面完全分離，核心公式附註解
  - 響應式設計，手機與平板可正常使用

## 快速開始

```bash
git clone https://github.com/jackywang869-cmyk/loan-calculator.git
cd loan-calculator
```

直接用瀏覽器開啟 `index.html` 即可（不需要建置步驟）。

若想用本機伺服器開啟：

```bash
npx serve .
# 或 python -m http.server 8000
```

本專案是純靜態檔案，可直接在 **Settings → Pages → Build and deployment → Deploy from a branch**，選擇分支（`main`）與目錄（`/ (root)`）後儲存，即可取得公開網址。

## 計算說明

核心公式（`loan-core.js` 內附註解）：

```
每期利率 r = 年利率 ÷ 100 ÷ 每年繳款期數

等額本息（每期還款額固定）
  M = P × r × (1 + r)^n ÷ [ (1 + r)^n − 1 ]        （r = 0 時退化為 M = P ÷ n）

等額本金（每期本金固定）
  每期本金 = P ÷ n（零頭留到末期）；每期利息 = 期初剩餘本金 × r
```

- **避免浮點誤差**：所有金額以「分」為單位的整數運算，每期利息四捨五入到分；**末期本金直接等於當期剩餘本金**，吸收所有尾差，因此最後一期剩餘本金必定為 `0`，本金總額必定等於貸款金額。
- **每期利息** = 該期期初剩餘本金 × 每期利率。
- 單位換算時會保留未取整的精確值，來回切換單位不會出現 `2.499996` 之類的漂移。

## 輸入驗證規則

| 欄位 | 規則 |
| --- | --- |
| 貸款金額 | 必填、須為數字、須 > 0、上限 1 兆 |
| 貸款期限 | 必填、須為數字、須 > 0、換算後須為整數月數、上限 600 個月（50 年）、須為繳款週期的整數倍 |
| 利率 | 必填、須為數字、不得為負數、年利率上限 100% |
| 還款方式 | 必選（等額本息 / 等額本金） |
| 繳款週期 | 月繳 / 季繳 / 半年繳 / 年繳 |

## 測試

```bash
npm install          # 只會安裝 jsdom（devDependency）
npm test             # 核心邏輯測試（88 項，不需套件也可以直接 node test-core.js）
npm run test:ui      # 介面冒煙測試（jsdom）
npm run test:all     # 兩者都跑
```

測試涵蓋：已知值比對（100 萬 / 30 年 / 6% → 月付 5,995.51）、本金總額守恆、末期剩餘本金為 0、逐期加總一致、零利率、季繳、各驗證分支，以及介面的錯誤提示與單位換算。
